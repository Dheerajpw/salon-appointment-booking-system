# Salon Appointment Booking System

A full-stack Salon Appointment Booking System built using Node.js, Express.js, MySQL, JWT, HTML, CSS and JavaScript.

The system allows customers to register, login, manage profiles, view services, check availability, book appointments, make online payments, reschedule/cancel appointments and submit reviews.

Admins can manage users, appointments, staff, services and customer reviews.

---

- User Login

- View Services
- View Staff

- Book Appointment
